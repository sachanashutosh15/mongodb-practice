LEVEL 1 — AGGREGATION FUNDAMENTALS

1. Product categories
Find each product category and the number of products in that category.
Suggested concepts: $group

db.products.aggregate([
    {
        $group: {
            _id: "$category",
            productCnt: {
                $sum: 1
            }
        }
    }
]);

2. Average price
Find the average product price for each category.
Return: category, averagePrice.

db.Products.aggregate([
    {
        $group: {
            _id: "$category",
            avgPrice: {
                $avg: "$price"
            }
        } 
    },
    {
        $project: {
            _id: 0,
            category: "$_id",
            averagePrice: "$avgPrice"
        }
    }
])

3. Expensive categories
Find categories whose average product price is greater than ₹10,000.

db.products.aggregate([

        }

6. Tags

LEVEL 2 — ARRAYS AND $UNWIND

7. Order items
Find the total quantity sold for each product across all orders.
Suggested concepts: $unwind, $group.

db.orders.aggregate([
    {
        $unwind: "$items"
    },
    {
        $group: {
            _id: "$items.productId",
            totalQuantity: {
                $sum: "$items.quantity"
            }
        }
    }
])

8. Product revenue
Calculate the total revenue generated by each product.
Revenue = quantity × unitPrice.
Return: productId, totalRevenue.

db.orders.aggregate([
    {
        $unwind: "$items"
    },
    {
        $group: {
            _id: "$items.productId",
            revenue: {
                $sum: {
                    $multiply: ["$items.quantity", "$items.unitPrice"]
                }
            }
        }
    },
    {
        $project: {
            _id: 0,
            productId: "$_id",
            totalRevenue: "$revenue"
        }
    }
])

9. Best-selling products
Find the top 5 products by quantity sold.

db.orders.aggregate([

                $sum: "$items.quantity"

    },

            soldQuantity: -1
        }
    },
    {
        $limit: 5
    }
])

        $unwind: "$user"
    }

15. User reviews
Return every review along with:
- review title
- rating
- user name
- product name.
This requires two $lookup operations.

db.reviews.aggregate([
    {
        $lookup: {
            from: "users",
            localField: "userId",
            foreignField: "_id",
            as: "user"
        }
    },
    {
        $unwind: "$user"
    },
    {
        $lookup: {
            from: "products",
            localField: "productId",
            foreignField: "_id",
            as: "product"
        }
    },
    {
        $unwind: "$product"
    },
    {
        $project: {
            reviewTitle: "$title",
            rating: 1,
            userName: "$user.name",
            productName: "$product.name"
        }
    }
])


LEVEL 4 — $LOOKUP WITH PIPELINES

16. High-value customers
Find users whose total spending on delivered orders is greater than ₹50,000.
Return:
- user
- totalSpent.

db.users.aggregate([
    {
        $lookup: {
            from: "orders",
            let: { userId: "$_id" },
            pipeline: [
                {
                    $match: {
                        $expr: {
                            $and: [
                                {
                                    $eq: ["$$userId", "$userId"]
                                },
                                {
                                    $eq: ["$status", "delivered"]
                                }
                            ]
                        }
                    }
                }
            ],
            as: "orders",
        }
    },
    {
        $project: {
            name: 1,
            totalSpenditure: {
                $sum: "$orders.totalAmount"
            }
        }
    },
    {
        $match: {
            totalSpenditure: {
                $gt: 50000
            }
        }
    }
])

17. Users with recent orders
Find users who have placed at least one order in the last 90 days.
Return the user and their matching orders.
Try putting the filtering inside the $lookup pipeline.

db.users.aggregate([
    {
        $lookup: {
            from: "orders",
            let: { userId: "$_id" },
            pipeline: [
                {
                    $match: {
                        $expr: {
                            $and: [
                                {
                                    $eq: ["$userId", "$$userId"]
                                },
                                {
                                    $gt: [
                                        "$orderDate",
                                        {
                                            $subtract: [
                                                "$$NOW",
                                                90 * 24 * 60 * 60 * 1000
                                            ]
                                        }
                                    ]
                                }
                            ]
                        }
                    }
                }
            ],
            as: "orders"
        }
    }
])

18. Highly rated products
Find products whose average rating is at least 4.5 and which have at least 3 reviews.
Return:
- product
- averageRating
- reviewCount.

db.products.aggregate([
    {
        $lookup: {
            from: "reviews",
            localField: "_id",
            foreignField: "productId",
            as: "reviews"
        }
    },
    {
        $addFields: {
            averageRating: {
                $avg: "$reviews.rating"
            },
            reviewCount: {
                $size: "$reviews"
            }
        }
    },
    {
        $match: {
            averageRating: {
                $gte: 4.5
            },
            reviewCount: {
                $gte: 3
            }
        }
    },
    {
        $project: {
            name: 1,
            averageRating: 1,
            reviewCount: 1
        }
    }
])
